You are a senior full-stack engineer. Your task is to debug and permanently fix the caption generation pipeline. Do NOT apply temporary fixes or suppress errors. Find the root cause, implement a production-ready solution, and verify it with end-to-end testing.

## Problem Summary

The application uploads a video successfully, but caption generation fails.

Observed issues:

- Upload completes successfully.
- UI stays on "Uploading..." or "Analyzing video..."
- Caption generation never finishes.
- Sometimes the backend returns:
  FireworksAIError: Failed to generate valid captions after 3 attempts. Last error: Partial extraction: got 3/4 captions. Missing: humorous_non_tech.
- Sometimes polling fails with:
  Failed to poll task: HTTP 500.
- The loading spinner sometimes never stops.

## Your Objectives

Debug the complete pipeline from start to finish and fix every issue.

Trace this entire flow:

Video Upload
→ Task Creation
→ Backend Processing
→ Fireworks AI Request
→ Polling
→ Response Parsing
→ Caption Validation
→ Database/API Response
→ Frontend Rendering

Determine exactly where the failure occurs.

## Investigation Checklist

### 1. Upload Pipeline

Verify:

- upload endpoint
- file storage
- task creation
- returned task ID
- task status updates

Ensure upload completes correctly before analysis begins.

### 2. Fireworks AI Request

Inspect:

- API request payload
- model configuration
- prompt
- temperature
- max tokens
- timeout
- retries

Log:

- request payload
- response payload
- HTTP status
- request ID
- latency
- raw model output

Verify the model actually returns all required captions.

### 3. Prompt Quality

Inspect the LLM prompt.

Ensure it explicitly requires EXACTLY these four fields:

{
  "formal": "...",
  "sarcastic": "...",
  "tech_humor": "...",
  "humorous_non_tech": "..."
}

Rules:

- JSON only
- No markdown
- No explanations
- No extra text
- All four fields are mandatory

Improve the prompt if necessary.

### 4. JSON Parsing

Inspect the parser.

Determine whether failures are caused by:

- invalid JSON
- missing fields
- incorrect field names
- markdown wrappers
- trailing commas
- malformed output

Implement resilient parsing that can recover valid JSON whenever possible.

### 5. Caption Validation

Inspect validation logic.

Find where validation rejects responses.

Investigate why:

humorous_non_tech

is frequently missing.

If only one caption is missing:

- regenerate only the missing caption when possible
- avoid regenerating the entire response unnecessarily

Provide clear validation errors.

### 6. Polling

Investigate the HTTP 500 polling error.

Verify:

- polling endpoint
- task lookup
- database state
- queue worker
- task lifecycle
- timeout handling
- race conditions

Ensure polling returns consistent statuses:

processing
completed
failed
